Overview

An end-to-end speech translation system using IPA (International Phonetic Alphabet) as an intermediate phonetic supervision signal inside the encoder. Rather than relying on orthographic representations, the model learns phonetic structure directly — aligning computational representations with the intrinsic structure of spoken language.

"Morgenstund hat Gold im Mund."
→ m ˈɔ ɾ ɡ ə n s t ˌʊ n t | h a t | ɡ ˈɔ l t | ɪ m | m ˈʊ n t
Process
WP 01
Data Preparation
Downloaded CoVoST 2 DE→EN (127,834 samples). Extracted 80-dim log-mel filterbank features from MP3 audio. Converted German text → IPA sequences using espeak-ng via phonemizer. Built homophone dictionary with POS-based disambiguation using Stanza. Saved aligned triplets (fbank, IPA, translation) as TSV.
WP 02
Model Architecture
Built encoder-decoder with 12-layer Transformer encoder + 6-layer Transformer decoder. Added Intermediate CTC Loss at encoder layer 6 targeting IPA sequences — key contribution. Used GPT2 tokenizer for English target vocabulary (50,265 tokens). Combined loss: λ × L_CTC + (1−λ) × L_CE with λ = 0.3.
WP 03
Training
Trained on H100 80GB GPU. 15 epochs with lr=1e-5, batch size=32. Loss decreased from 2.14 → 0.54 with consistent convergence. Checkpoint system for resumable training across sessions.
WP 04
Homophone Resolution
Built IPA → word dictionary from training data. Identified 23 homophone groups (e.g. /m ˈeː ɾ/ → {mehr, meer}). POS-based disambiguation using Stanza to resolve ambiguous IPA sequences in context.

Key Contribution
Intermediate CTC Loss embedded at encoder layer 6 forces the model to learn phonetically grounded representations — enabling cross-lingual transfer without relying on orthographic systems, while maintaining full end-to-end trainability.
