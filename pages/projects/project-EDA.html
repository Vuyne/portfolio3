Overview

A comprehensive exploratory data analysis project spanning multiple real-world datasets. Using the full Python data stack — Pandas for wrangling, Matplotlib for static plots, Plotly Express for interactive visualisations — the work uncovers hidden patterns, outliers, distributions, and relationships across varied data domains.

Process
STEP 01
Data Ingestion & Cleaning
Loaded multiple datasets, handled missing values, removed duplicates, normalised data types, and documented each dataset's provenance and structure.
STEP 02
Univariate Analysis
Examined individual feature distributions using histograms, KDE plots, and box plots. Identified skewness, outliers, and key statistical summaries per column.
STEP 03
Multivariate Exploration
Investigated relationships between features through grouped bar charts, scatter plots with colour-encoded categories, and interactive Plotly Express charts for dynamic drill-down views.
STEP 04
Insight Communication
Documented findings in structured Jupyter notebooks with annotated charts, written observations, and reproducible code blocks for each dataset.
Outcome
A reproducible EDA pipeline adaptable to any tabular dataset — demonstrating fluency across the full analysis workflow from raw ingestion to actionable insight, with both static and interactive visualisation outputs.
