Overview

A physics-accurate drone racing simulation set within Olympic-style obstacle courses, built in Unity with a two-person team. The project focuses on realistic quadrotor flight dynamics — thrust, torque, and drag — mapped to intuitive player controls, with timed lap mechanics and structured course checkpoints.

My Contribution
Vy Lo — Main Coder
Drone flight physics — Rigidbody force/torque model, rotor thrust simulation, drag coefficients
Player input system — throttle, pitch, roll, yaw mapped to keyboard/controller
Checkpoint & lap timer system — trigger zones, ghost replay data, best-lap tracking
HUD elements — speedometer, altitude, lap time, checkpoint counter
Partner: course/environment design & asset integration
Process
STEP 01
Flight Physics Model
Implemented quadrotor dynamics using Unity Rigidbody — four virtual rotors apply upward thrust proportional to throttle input, with torque for yaw rotation and asymmetric thrust for pitch and roll.
STEP 02
Input & Control Tuning
Mapped player inputs to rotor differentials. Iterated on sensitivity curves and added drag damping to prevent oscillation — balancing realism with playability.
STEP 03
Checkpoint & Race Logic
Built an ordered checkpoint system using trigger colliders. Implemented lap timing, invalid-lap detection for missed gates, and persistent best-lap storage.
STEP 04
HUD & Feedback Systems
Designed in-game HUD displaying real-time speed, altitude, throttle level, and lap splits. Added audio cues for checkpoint passes and course completion.
Outcome
A fully playable drone racing simulation with physically grounded flight feel — demonstrating deep integration between physics simulation, real-time HUD systems, and structured race logic within a collaborative production pipeline.
