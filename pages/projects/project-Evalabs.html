Overview

A mixed-reality duck whack-a-mole game built in Unreal Engine 5.6 for Meta Quest, integrated into a shared "smart room" project with three teammates. Ducks spawn randomly throughout the physical room using MRUK Scene Understanding. The game features five distinct play modes — from simple tap-to-score to physics-based throwing and wearable thumb-sensor grab input streamed live from an ESP32.

Game Modes
Casual
Touch duck with hand → score. Ducks respawn randomly in room.
Hardcore
Per-duck time limit. Miss before timer expires → lose a life.
Catch & Carry
Grab duck with thumb sensor, carry to Nest, release to score.
Duck Toss
Grab rubber duck, throw with real physics into Nest to score.
Jumping Duck
Baby ducks hop away from Nest — catch and return them to score.
