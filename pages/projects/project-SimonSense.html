Overview

A hardware Simon Says game built entirely from scratch — four coloured LEDs, four tactile buttons, a piezo buzzer for tonal feedback, and progressive difficulty logic running on Arduino. The entire circuit is laid out on a custom PCB designed in Eagle, moving beyond breadboard to a proper soldered board.

Process
STEP 01
Game Logic & Sequence Engine
Implemented the core Simon Says state machine in C++ — sequence generation using seeded random, playback with LED + tone pairs, player input capture with debounce, and fail detection on wrong input or timeout.
STEP 02
Progressive Difficulty
Each successful round appends one step to the sequence and reduces playback delay — sequence speed accelerates from 600ms down to 200ms at high levels, with a win animation at round 20.
STEP 03
PCB Design in Eagle
Designed the schematic and PCB layout in Eagle — four LED driver circuits with current-limiting resistors, pull-down resistor button inputs, piezo buzzer output pin, and clean Arduino header footprint for plug-in mounting.
STEP 04
Assembly & Testing
Soldered all components to the fabricated PCB. Tested each channel independently for LED brightness consistency and button debounce timing, then full game-loop integration testing across difficulty levels.
Outcome
A fully playable standalone Simon Says game on a custom PCB — demonstrating end-to-end embedded hardware development from schematic capture and PCB layout through to soldered assembly and polished gameplay logic with progressive difficulty.
