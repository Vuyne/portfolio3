Overview

A handheld geocaching device built around Arduino — reads live GPS coordinates, calculates bearing and distance to a stored target cache location, and guides the user via LCD display and a directional compass needle. Fully self-contained and battery-powered for outdoor field use.

Hardware Spec
MCU
Arduino Uno / Nano
GPS
NEO-6M UART module — NMEA sentence parsing
Display
16×2 I²C LCD — bearing, distance, coordinate readout
Navigation
Haversine formula for great-circle distance & bearing
Power
9V battery with 5V regulated supply
Process
STEP 01
GPS Parsing & Coordinate Extraction
Wired the NEO-6M GPS module via UART. Parsed incoming NMEA $GPRMC sentences in C++ to extract latitude, longitude, and fix validity — with fault handling for no-signal states.
STEP 02
Navigation Mathematics
Implemented the Haversine formula to compute great-circle distance between current position and stored cache coordinates. Added atan2-based bearing calculation returning compass heading in degrees.
STEP 03
LCD Interface & UX
Designed a two-screen LCD layout — top line shows distance to target in metres, bottom line shows compass bearing and cardinal direction. Updates every GPS fix cycle (~1Hz).
STEP 04
Cache Storage & Found State
Stored target coordinates in EEPROM for persistence across power cycles. Implemented arrival detection — triggers a found animation and sound when within 5 metres of the cache.
Outcome
A working field-ready GPS geocaching device — demonstrating UART sensor integration, real-time coordinate mathematics, EEPROM data persistence, and intuitive embedded UI design in a fully battery-powered solo build.
